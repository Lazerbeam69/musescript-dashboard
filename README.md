# MuseScript Dashboard

A modern, responsive web dashboard for monitoring and managing MuseScript projects.

## Features

- 📊 Real-time project statistics
- 📈 Success rate monitoring
- 🔄 Live activity feed
- 💻 Responsive design
- 🎨 Modern UI with gradient themes

## Getting Started

### Prerequisites

- A modern web browser
- Python 3 (for local development server)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/lazerbeam69/musescript-dashboard.git
cd musescript-dashboard
```

2. Open the dashboard:
   - **Option 1**: Open `index.html` directly in your browser
   - **Option 2**: Run a local server:
     ```bash
     python3 -m http.server 8000
     ```
     Then navigate to `http://localhost:8000`

## Usage

The dashboard provides:
- **Active Projects**: Monitor the number of running projects
- **Scripts Executed**: Track total script executions
- **Success Rate**: View script success percentage
- **System Status**: Check system health
- **Recent Activity**: View recent script executions and events
